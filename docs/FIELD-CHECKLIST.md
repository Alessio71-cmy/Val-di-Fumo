## C. Dopo l'escursione (restituire i dati)

1. Correggere i testi in `src/content/*` (segnavia, avvertenze, tempi) e portare gli elementi realmente confermati a **`field-verified`** con la data (`validation`, `lastVerified`).
2. Se si dispone di una traccia GPX registrata o ufficiale **con provenienza nota**, usarla per sostituire/validare la geometria (oggi l'app la importa solo per il confronto) e rieseguire la pipeline (`scripts/geodata`).
3. Rigenerare i documenti (`npm run docs:itinerary`, `python3 scripts/geodata/render_docs.py`), eseguire `npm run test:all`, ripubblicare.
4. Aggiornare [TEST-REPORT.md](TEST-REPORT.md) con le prove **su dispositivo** eseguite (installazione iPhone/Android, secondo dispositivo, modalità aereo reale, GPS reale).
